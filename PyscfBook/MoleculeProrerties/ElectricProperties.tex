%% ========================================================
\section{Електричні властивості молекул}\label{sec:elprop}
%% ========================================================

Електричні властивості --- це найпростіший і водночас фундаментальний приклад застосування теорії відгуку.
Вони описують, як розподіл електронної густини в молекулі реагує на дію зовнішнього електричного поля~$\mathbf{E}$.

При накладенні поля змінюється гамільтоніан системи:
\[
\hat{H} = \hat{H}_0 - \hat{\boldsymbol{\mu}}\cdot \Efield,
\]
де $\hat{\boldsymbol{\mu}} = -\sum_i e\,\mathbf{r}_i$ --- оператор електричного дипольного моменту.

Згідно з теоремою Геллмана–Фейнмана, перша похідна енергії за полем визначає
\textbf{дипольний момент молекули}:
\[
\mu_\alpha = -\frac{\partial E}{\partial E_\alpha}.
\]
Друга похідна енергії за полем описує \textbf{електричну поляризованість}:
\[
\alpha_{\alpha\beta} = -\frac{\partial^2 E}{\partial E_\alpha \partial E_\beta}.
\]
Поляризованість характеризує, наскільки сильно електронна хмара молекули деформується під дією поля,
а її анізотропія визначає оптичні властивості, зокрема інтенсивність Раманівських переходів.

%% --------------------------------------------------------
\subsection{Розрахунок у PySCF}
%% --------------------------------------------------------

У \texttt{PySCF} електричні властивості можуть бути обчислені як чисельно (через кінцеві різниці енергій при малих збуреннях поля),
так і аналітично --- через розв’язання рівнянь відгуку (\texttt{CPHF/CPKS}).

Приклад розрахунку дипольного моменту:
\begin{minted}{python}
from pyscf import gto, scf

mol = gto.Mole(atom='O 0 0 0; H 0 0 1; H 0 1 0', basis='sto-3g')
mol.build()

mf = scf.RHF(mol).run()
print('Dipole moment (Debye):', mf.dip_moment(unit='Debye'))
\end{minted}

Поляризованість розраховується подібним чином,
але з використанням модуля \texttt{properties.polarizability} або прямим вмиканням відгуку:
\begin{lstlisting}[language=Python, caption={Поляризованість через CPHF}]
from pyscf import prop

pol = prop.polarizability.Polarizability(mf)
print(pol.kernel())
\end{lstlisting}

У параметрі \inlinecode{cphf=True} вмикається самозгоджене врахування варіацій орбіталей у полі,
що забезпечує повну (релаксовану) поляризованість.
