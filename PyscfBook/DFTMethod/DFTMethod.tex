\chapter{Теорія функціоналу густини (DFT)}\label{\currfilebase}
%=========================================================

Розглянуті вище пост-Хартрі–Фоківські методи показують, як поступово можна вдосконалювати апроксимацію Хартрі–Фока, враховуючи електронну кореляцію шляхом розширення хвильової функції. Однак усі ці підходи залишаються в межах \emph{хвильово-функціональної парадигми}, що швидко стає обчислювально непідйомною для великих систем.

У спробі знайти простішу, але фізично змістовну альтернативу було запропоновано іншу концепцію --- опис електронної системи через \emph{густину електронів} $\rho(\mathbf{r})$, що залежить лише від трьох просторових координат. Історично її витоки сягають \textbf{моделі Томаса–Фермі}, яка вперше пов’язала енергію електронного газу з його густиною. Хоч ця модель була грубою, саме з неї виросла сучасна \textbf{теорія функціонала густини (DFT)}, що поєднує фізичну інтуїцію з математичною строгістю і стала одним із найпотужніших інструментів сучасної квантової хімії.

Ідея моделі Томаса–Фермі полягає в тому, що
енергію системи можна виразити як функціонал від густини:
\[
E[\rho] = T_\text{TF}[\rho]
+ \int v_\text{ext}(\mathbf{r})\,\rho(\mathbf{r})\,d\mathbf{r}
+ \frac{1}{2}\iint
\frac{\rho(\mathbf{r})\,\rho(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|}
\,d\mathbf{r}\,d\mathbf{r}' ,
\]
де $T_\text{TF}[\rho]$ --- наближення до кінетичної енергії,
отримане для однорідного електронного газу.
Мінімізація цього функціонала за $\rho(\mathbf{r})$
при фіксованій кількості електронів
\[
\int \rho(\mathbf{r})\,d\mathbf{r} = N
\]
дає рівноважний розподіл густини для основного стану.

Попри свою простоту, модель Томаса–Фермі стала першим кроком
до \emph{безхвильового} опису багаточастинкових систем.
Вона виявилася якісно правильною для дуже великих атомних номерів,
але не могла відтворювати хімічний зв’язок,
тонку структуру електронної густини
та ефекти обміну й кореляції.

Саме спроби подолати ці обмеження призвели до народження
\textbf{теорії функціонала густини (DFT)}.
На відміну від моделі Томаса–Фермі,
DFT базується на строгих теоремах Хоенберга–Кона,
які гарантують існування точного функціонала енергії від густини
та формують основу сучасних обчислювальних методів квантової хімії.

\section{Практичні рекомендації}
%% --------------------------------------------------------

\begin{enumerate}
    \item \textbf{Для простих молекул (H$_2$, N$_2$, O$_2$)}:
    \begin{itemize}
        \item Базовий розрахунок: PBE/cc-pVTZ
        \item Висока точність: PBE0/aug-cc-pVQZ
        \item Найкраща точність: CCSD(T)/aug-cc-pV5Z
    \end{itemize}

    \item \textbf{Для полярних молекул (CO, NO, HF)}:
    \begin{itemize}
        \item Гібридні функціонали обов'язкові
        \item Дифузні функції для дипольних моментів
    \end{itemize}

    \item \textbf{Для молекул перехідних металів}:
    \begin{itemize}
        \item TPSSh або M06 функціонали
        \item Велика кількість спінових станів
        \item Можливо, потрібен DFT+U
    \end{itemize}

    \item \textbf{Для слабких зв'язків}:
    \begin{itemize}
        \item Обов'язкові дисперсійні корекції (D3, D4)
        \item Або ωB97X-D, M06-2X функціонали
    \end{itemize}

    \item \textbf{Для збуджених станів}:
    \begin{itemize}
        \item TD-DFT з range-separated функціоналами
        \item Або багатоконфігураційні методи (CASSCF)
    \end{itemize}
\end{enumerate}

%% --------------------------------------------------------
\subsection{Типові помилки при розрахунках молекул}
%% --------------------------------------------------------

\begin{enumerate}
    \item \textbf{Неправильна симетрія}:
    \begin{itemize}
        \item Завжди використовуйте симетрію молекули
        \item Перевіряйте point group командою \inlinecode{mol.symmetry = True}
    \end{itemize}

    \item \textbf{Хибна мультиплетність}:
    \begin{itemize}
        \item O$_2$ --- триплет, не синглет!
        \item Перевіряйте спін по \inlinecode{mol.spin}
    \end{itemize}

    \item \textbf{Недостатня сітка інтегрування}:
    \begin{itemize}
        \item Для точних градієнтів: \inlinecode{grids.level = 4}
        \item Для оптимізації завжди перевіряйте конвергенцію по сітці
    \end{itemize}

    \item \textbf{Погана початкова геометрія}:
    \begin{itemize}
        \item Починайте з розумних відстаней
        \item Використовуйте експериментальні дані або попередні розрахунки
    \end{itemize}

    \item \textbf{Ігнорування BSSE} (Basis Set Superposition Error):
    \begin{itemize}
        \item Для енергій зв'язування використовуйте counterpoise корекцію
        \item Особливо важливо для малих базисів
    \end{itemize}
\end{enumerate}

\nosection{Резюме}
%% --------------------------------------------------------

Теорія функціоналу густини (\texttt{DFT}) є сучасною альтернативою
пост-Хартрі--Фоківським методам для розв’язання багатоелектронної задачі.
На відміну від методів, що оперують хвильовою функцією, \texttt{DFT}
використовує лише електронну густину $\rho(\mathbf{r})$ як основну змінну.
Це суттєво спрощує обчислення та дозволяє досліджувати великі системи.

\begin{itemize}
    \item Теореми Хоенберга--Кона (1964) доводять, що:
    \begin{enumerate}
        \item зовнішній потенціал $v_\mathrm{ext}(\mathbf{r})$ і, отже, вся енергія системи
        однозначно визначаються густиною $\rho(\mathbf{r})$;
        \item існує варіаційний принцип: основний стан відповідає мінімуму
        функціонала енергії $E[\rho]$.
    \end{enumerate}

    \item Рівняння Кона--Шема (1965) переводять задачу взаємодіючих електронів
    у рівняння для невзаємодіючих частинок, що рухаються в ефективному потенціалі:
    \[
    \hat{F}_\mathrm{KS} \psi_i = \varepsilon_i \psi_i,
    \quad
    \hat{F}_\mathrm{KS} = -\tfrac{1}{2}\nabla^2 + v_\mathrm{ext} + v_\mathrm{H} + v_\mathrm{xc},
    \]
    де $v_\mathrm{xc}(\mathbf{r}) = \delta E_\mathrm{xc}[\rho]/\delta\rho$ — обмінно-кореляційний потенціал.

    \item Уся складність \texttt{DFT} зосереджена у виборі функціонала $E_\mathrm{xc}[\rho]$.
    Його форма визначає точність і область застосування методу.

    \item Класифікація функціоналів (так звана «драбина Якова»):
    \begin{enumerate}
        \item \texttt{LDA}, \texttt{LSDA} --- локальне наближення густини, базується на однорідному електронному газі;
        \item \texttt{GGA} --- ураховує градієнт густини ($\nabla\rho$), підвищуючи точність для молекул;
        \item \texttt{meta-GGA} --- включає кінетичну густину $\tau(\mathbf{r})$ або лапласіан густини $\nabla^2\rho$;
        \item гібридні функціонали --- поєднують локальні внески з точним обміном (\texttt{HF}) у певній пропорції.
    \end{enumerate}

    \item Вибір функціоналу визначає баланс між точністю, універсальністю та обчислювальними затратами.
    Наприклад, \texttt{PBE} і \texttt{BLYP} є стандартними неемпіричними GGA-функціоналами,
    тоді як \texttt{B3LYP} і \texttt{PBE0} --- гібридні, що забезпечують найкраще відтворення експериментальних даних.

    \item Порівняно з методом Хартрі--Фока, \texttt{DFT} включає електронну кореляцію ефективно через $E_\mathrm{xc}[\rho]$
    і має кращу масштабованість ($O(N^3)$ проти $O(N^4)$ для \texttt{HF}), що робить його основним інструментом
    сучасних молекулярних і матеріалознавчих розрахунків.

    \item Водночас точність \texttt{DFT} залежить від вибраного функціонала та може бути обмеженою
    у випадках сильно корельованих або збуджених станів, де більш адекватними є багатоконфігураційні методи.
\end{itemize}

Таким чином, теорія функціоналу густини забезпечує найкращий компроміс
між фізичною обґрунтованістю, точністю та обчислювальною ефективністю.
Вона стала основним робочим інструментом у квантовій хімії, фізиці твердого тіла
та моделюванні складних матеріалів.

\subsection*{Контрольні запитання}
%% --------------------------------------------------------

\begin{enumerate}
	\item Які основні теореми лежать в основі теорії функціоналу густини (DFT)? Опишіть їх суть та значення для обчислень.
	\item Поясніть, що таке рівняння Кона-Шема. Як вони пов'язані з рівняннями Хартрі--Фока?
	\item Опишіть класифікацію обмінно-кореляційних функціоналів за ``драбинкою Якова''. Наведіть приклади для кожного рівня.
	\item Чим відрізняються LDA та GGA функціонали? Наведіть приклади та області застосування.
	\item Що таке гібридні функціонали? Як вони поєднують елементи HF та DFT? Наведіть приклад розрахунку з B3LYP.
	\item Які переваги та недоліки DFT порівняно з пост-HF методами? Коли DFT є кращим вибором?
	\item Поясніть роль ефективного потенціалу $v_{\text{eff}}(\vect{r})$ у DFT. Як обчислюється обмінно-кореляційна частина?
\end{enumerate}

\subsection*{Практичні завдання}

\begin{tasks}

\item Побудуйте криві потенційної енергії молекули \ce{F2} різними функціоналами (\texttt{LDA}, \texttt{PBE}, \texttt{B3LYP}, \texttt{PBE0}) та порівняйте з експериментом ($r_e = 1.412$~\AA, $D_e = 1.66$~eV).

\item Дослідіть вплив базисного набору на властивості \ce{CO}: розрахуйте $r_e$, $D_e$, $\omega_e$ з базисами \texttt{cc-pVDZ}, \texttt{cc-pVTZ}, \texttt{cc-pVQZ} та екстраполюйте до межі.

\item Порівняйте RKS та UKS підходи для дисоціації \ce{H2}. Поясніть різницю в поведінці енергії на великих відстанях.

\item Розрахуйте перші три збуджені стани \ce{N2} методом TD-DFT з різними функціоналами. Порівняйте з експериментальними значеннями.

\item Дослідіть молекулу \ce{CuH} методами \texttt{PBE}, \texttt{TPSSh} та \texttt{B3LYP}. Який функціонал краще описує зв'язок \ce{Cu-H}?

\item Виконайте систематичне дослідження галогенів (\ce{F2}, \ce{Cl2}, \ce{Br2}, \ce{I2}) з різними функціоналами. Який функціонал найкраще відтворює експериментальні енергії дисоціації?

\item Побудуйте benchmark для молекул \ce{H2}, \ce{N2}, \ce{CO} з базисами від \texttt{cc-pVDZ} до \texttt{aug-cc-pV5Z}. Визначте, при якому базисі досягається конвергенція з точністю 1~mHa.

\item Розрахуйте тестовий набір G2 (8 молекул) функціоналами \texttt{PBE}, \texttt{B3LYP}, \texttt{PBE0}, \texttt{M06-2X}. Порівняйте MAE, RMSE та визначте найкращий функціонал.

\item Розрахуйте енергії всіх атомів третього періоду (\ce{Na}--\ce{Ar}) з функціоналами \texttt{PBE}, \texttt{B3LYP} та \texttt{PBE0}. Порівняйте результати з \texttt{HF}. Побудуйте графіки.

\textbf{Базис:} \texttt{def2-TZVP}

\item Для атома Заліза (\ce{Fe}) порівняйте енергії різних спінових станів ($2S = 0, 2, 4, 6$) використовуючи функціонали: \texttt{LDA}, \texttt{PBE}, \texttt{TPSS}, \texttt{B3LYP}, \texttt{PBE0}.

\begin{itemize}
    \item Який спіновий стан є найнижчим для кожного функціоналу?
    \item Який функціонал дає правильний основний стан?
\end{itemize}

\item Для атома Неону розрахуйте енергію з функціоналом \texttt{PBE0} та базисами \texttt{cc-pVDZ}, \texttt{cc-pVTZ}, \texttt{cc-pVQZ}, \texttt{cc-pV5Z}.

Екстраполюйте енергію до базисної межі (CBS) за формулою:
\[
E(X) = E_{\text{CBS}} + \frac{A}{X^3}
\]
де $X = 2, 3, 4, 5$ для DZ, TZ, QZ, 5Z.

Порівняйте з експериментальною енергією \ce{Ne}: \textbf{-128.547 eV}

\item Розрахуйте всі 3d перехідні метали (\ce{Sc}--\ce{Zn}) з функціоналом \texttt{TPSSh}. Проаналізуйте заселеності d-орбіталей.

Для яких атомів:
\begin{enumerate}
    \item Всі d-орбіталі рівномірно заселені?
    \item Є виражена асиметрія $\alpha/\beta$?
    \item Найбільше забруднення спіном?
\end{enumerate}


\end{tasks}
