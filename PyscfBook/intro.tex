\chapter*{Передмова}
\addcontentsline{toc}{chapter}{Передмова}

Цей навчальний посібник є практичним введенням у квантово-хімічні розрахунки атомних і молекулярних систем з використанням сучасного програмного пакета PySCF (\emph{Python-based Simulations of Chemistry Framework}). Посібник орієнтований на студентів, аспірантів і дослідників, які прагнуть зрозуміти принципи побудови квантово-механічних моделей та навчитися ефективно виконувати обчислення з використанням відкритих інструментів. Відкриті програмні пакети, зокрема PySCF, забезпечують прозорість алгоритмів, відтворюваність результатів і формують сучасну культуру досліджень, де користувач розуміє не лише результат, а й принцип роботи методу.


%% --------------------------------------------------------
\nosection{Актуальність квантово-механічних методів}
%% --------------------------------------------------------

Сучасна наука про матеріали --- зокрема галузі \textbf{прикладної фізики, наноматеріалів, електроніки та каталізу} --- переживає справжню революцію: від емпіричних експериментів ми переходимо до \textbf{передбачувального моделювання} на атомно-молекулярному рівні. Сьогодні фізик може «зазирнути» всередину речовини --- побачити, як електрони формують зв’язки і передбачити властивості матеріалу ще до того, як він буде створений у лабораторії.

Попри назву ``квантова хімія’’, ця галузь є прямим продовженням \textbf{квантової фізики багаточастинкових систем}. Її завдання --- не лише описувати реакції чи сполуки, а й \textbf{розраховувати електронну структуру, потенціальні поверхні та властивості речовини}, що визначають поведінку матеріалів у реальних фізичних процесах. Тому квантово-хімічні методи сьогодні стали невід’ємною частиною фізики твердого тіла, нанофізики, оптики, спінтроніки та матеріалознавства.

\textbf{Квантово-механічні обчислення} відкривають можливість експериментувати з матерією без реактивів і складних установок --- просто у комп’ютерній моделі. Вони дозволяють:
\begin{itemize}
    \item передбачати електронну структуру та енергетичні рівні з високою точністю;
    \item розраховувати енергії зв’язку, спектри, оптичні переходи та потенціальні бар’єри;
    \item оптимізувати структури та властивості матеріалів за допомогою комп’ютерного моделювання (\emph{in silico}) перед експериментальним синтезом.
\end{itemize}

Цей підхід поєднує фундаментальну фізику з сучасними обчислювальними методами і відкриває шлях до розуміння та створення нових матеріалів --- від надпровідників до квантових точок і двовимірних систем.

%% --------------------------------------------------------
\subsection*{Робота з кодом}
%% --------------------------------------------------------

Код із посібника можна запускати кількома способами.

\paragraph{1. \texttt{Jupyter Notebook} (рекомендовано для навчання)}

Jupyter Notebook --- інтерактивне середовище, ідеальне для навчання та експериментів:

\begin{minted}{bash}
# Встановлення Jupyter
pip install jupyter

# Запуск
cd pyscf_atomic_tutorial/notebooks
jupyter notebook
\end{minted}

\textbf{Переваги:}
\begin{itemize}
    \item покрокове виконання коду (cell-by-cell);
    \item миттєвий перегляд результатів;
    \item автоматичне збереження графіків і таблиць;
    \item можливість додавати власні коментарі та формули;
    \item легке поширення серед колег і студентів.
\end{itemize}

\paragraph{2. Окремі Python-скрипти}

Усі приклади можна запускати як звичайні скрипти:
\begin{minted}{bash}
python 01_hf_hydrogen.py
python -u 02_hf_helium.py > output.log
\end{minted}

Такий підхід зручний для:
\begin{itemize}
    \item пакетного виконання розрахунків;
    \item запуску на кластерах чи серверах;
    \item інтеграції у власні обчислювальні workflow.
\end{itemize}

\paragraph{3. Інтерактивний Python (\texttt{iPython})}

Для швидких перевірок і тестів:
\begin{minted}{python}
ipython
>>> from pyscf import gto, scf
>>> mol = gto.M(atom='H 0 0 0', basis='sto-3g', spin=1)
>>> mf = scf.UHF(mol)
>>> mf.kernel()
\end{minted}

\paragraph{4. IDE (\texttt{PyCharm}, \texttt{VS Code}, \texttt{Spyder})}

Використання IDE дозволяє:
\begin{itemize}
    \item налаштувати автодоповнення та перевірку синтаксису;
    \item зручно налагоджувати код (debugging);
    \item працювати з Git та контролем версій.
\end{itemize}

\textit{``Якщо я бачив далі, то тому, що стояв на плечах гігантів.''}\\
