\section{PySCF: концепція та філософія}
%% --------------------------------------------------------

PySCF (\emph{Python-based Simulations of Chemistry Framework}) --- це сучасний відкритий програмний пакет для квантово-хімічних розрахунків, написаний переважно на мові Python з критичними для продуктивності компонентами на \texttt{C}.
Розроблений під керівництвом професора \emph{Garnet Chan} у Каліфорнійському технологічному інституті, PySCF став новим стандартом відкритої наукової платформи, яка поєднує:
\begin{itemize}
    \item простоту навчання;
    \item гнучкість експериментування;
    \item високу точність і масштабованість.
\end{itemize}

Його головна ідея --- зробити квантову хімію \emph{прозорою та інтерактивною}.
Замість монолітних пакетів із власними скриптовими мовами (\texttt{Gaussian}, \texttt{ORCA}), PySCF використовує чистий Python, дозволяючи виконувати розрахунки без компіляції, прямо в \texttt{Jupyter Notebook} або \texttt{Google Colab}.

Проєкт започаткований \emph{Qiming Sun} у співпраці з \emph{Garnet K.-L. Chan} та міжнародною командою розробників, серед яких \emph{Sandeep Sharma}, \emph{Thomas Berkelbach}, \emph{Zhendong Li} та інші, що зробили внесок у розвиток модулів \texttt{HF}, \texttt{DFT}, \texttt{CC}, \texttt{DMRG} та \texttt{PBC}.

Актуальна стабільна версія пакета (на час написання книги) — \textbf{PySCF v2.11.0} (див. \url{https://github.com/pyscf/pyscf/releases}).

\section{Основні можливості PySCF}
%% --------------------------------------------------------

PySCF підтримує широкий спектр квантово-хімічних методів:

\begin{itemize}
    \item \textbf{Метод Хартрі---Фока (\texttt{HF}):} \texttt{RHF}, \texttt{UHF}, \texttt{ROHF}.
    \item \textbf{Теорія функціонала густини (\texttt{DFT}):} інтеграція з бібліотекою \texttt{libxc}.
    \item \textbf{Post-Hartree–Fock методи:} \texttt{MP2}, \texttt{CCSD}, \texttt{CCSD(T)}, \texttt{CASSCF}, \texttt{CASPT2}, \texttt{NEVPT2}.
    \item \textbf{Configuration Interaction (\texttt{CI}):} \texttt{CISD}, \texttt{Full CI}.
    \item \textbf{Релятивістські методи:} \texttt{ECP}, \texttt{X2C}, чотирикомпонентні \texttt{HF}/\texttt{MP2}.
    \item \textbf{Періодичні системи:} модуль \texttt{PBC} --- \texttt{HF}, \texttt{DFT}, \texttt{MP2}, \texttt{CCSD}.
    \item \textbf{Явна кореляція:} \texttt{F12}-методи.
    \item \textbf{Багаторівневі підходи:} \texttt{ONIOM}, embedding.
    \item \textbf{Інтегральні трансформації:} перетворення AO/MO інтегралів.
    \item \textbf{Density fitting:} прискорення обчислень великих систем.
\end{itemize}

%% --------------------------------------------------------
\section{Архітектура і дизайн PySCF}
%% --------------------------------------------------------

\paragraph{Ключові принципи.}
\begin{enumerate}
    \item \textbf{Простота} --- мінімум прихованої логіки, усе у вигляді Python-коду;
    \item \textbf{Універсальність} --- підтримка молекул, кластерів і кристалів;
    \item \textbf{Ефективність} --- продуктивність наближена до реалізацій на Fortran/C.
\end{enumerate}

\paragraph{Архітектурний принцип.}
Кожен метод реалізує універсальну функцію \inlinecode{.kernel()}, яка запускає розрахунок незалежно від рівня теорії:

\begin{minted}{python}
from pyscf import scf, mp
mf = scf.RHF(mol).run()
e_mp2 = mp.MP2(mf).kernel()
\end{minted}

\paragraph{Модульна структура.}
\begin{itemize}
    \item \texttt{gto} --- геометрія, базис, інтеграли;
    \item \texttt{scf} --- методи Хартрі---Фока і \texttt{DFT};
    \item \texttt{mp}, \texttt{cc}, \texttt{ci} --- пост-Хартрі–Фоківські методи;
    \item \texttt{mcscf}, \texttt{dmrgscf}, \texttt{fciqmc} --- багатоконфігураційні;
    \item \texttt{pbc} --- періодичні системи;
    \item \texttt{lib} --- оптимізовані обчислення інтегралів (\texttt{Libcint}).
\end{itemize}

\paragraph{Інтеграція з Python-екосистемою.}
Результати розрахунків --- це звичайні Python-об’єкти (\texttt{NumPy}-масиви, списки, словники), які можна одразу візуалізувати або обробити.

\paragraph{Паралельні обчислення.}
PySCF підтримує:
\begin{itemize}
    \item внутрішній багатопоточний паралелізм (OpenMP);
    \item MPI-кластеризацію із сервер-клієнт архітектурою;
    \item однаковий код у серійному та паралельному режимах.
\end{itemize}

\paragraph{Прозорість коду.}
PySCF --- це не «чорна скринька», а лабораторія для експериментів.
Будь-який SCF-цикл, побудова матриці Фока або перетворення інтегралів --- доступні для перегляду і модифікації.

\subsection{Системні вимоги}

Для роботи з PySCF необхідно:
\begin{itemize}
    \item Python 3.7 або новіший
    \item NumPy версії 1.13.0 або новішої
    \item SciPy версії 1.0.0 або новішої
    \item H5py (для збереження великих масивів даних)
    \item 4--8 ГБ оперативної пам'яті (мінімум)
    \item Сучасний процесор (бажано багатоядерний)
\end{itemize}

%% --------------------------------------------------------
\subsection{Встановлення в Linux}
%% --------------------------------------------------------

Найпростіший спосіб встановлення PySCF у Linux --- використання pip:

\begin{minted}{bash}
# Оновлення pip
pip install --upgrade pip

# Встановлення PySCF
pip install pyscf
\end{minted}

Для встановлення з додатковими можливостями:

\begin{minted}{bash}
# З підтримкою XC функціоналів
pip install pyscf[geomopt,dftd3,dmrgscf]
\end{minted}

Якщо потрібно встановити всі опціональні модулі PySCF:

\begin{minted}{bash}
# Повне встановлення з усіма підтримуваними розширеннями
pip install pyscf[all]
\end{minted}

Альтернативно, можна встановити з вихідного коду:

\begin{minted}{bash}
git clone https://github.com/pyscf/pyscf.git
cd pyscf
pip install -e .
\end{minted}

%% --------------------------------------------------------
\subsection{Перевірка встановлення}
%% --------------------------------------------------------

Після встановлення перевіримо, чи PySCF працює коректно:
\begin{minted}{python}
import pyscf
# Вивід версії
print(pyscf.__version__)
# Простий тест
from pyscf import gto, scf
mol = gto.M(atom='H 0 0 0; H 0 0 0.74', basis='sto-3g')
mf = scf.RHF(mol)
energy = mf.kernel()
print(f'Енергія H2: {energy:.6f} Ha')
\end{minted}

Якщо програма виводить версію та обчислює енергію молекули H$_2$, встановлення виконано успішно.

%% --------------------------------------------------------
\subsection{Запуск PySCF у Docker}
%% --------------------------------------------------------

PySCF також можна запускати у готовому контейнері \texttt{Docker}, що особливо зручно для відтворюваних розрахунків та роботи на серверних системах без прямого доступу до Python-середовища.

\paragraph{Встановлення Docker.}
Для початку встановіть Docker відповідно до вашої операційної системи:
\begin{itemize}
  \item Linux: \url{https://docs.docker.com/engine/install/ubuntu/}
  \item Windows/macOS: \url{https://www.docker.com/products/docker-desktop}
\end{itemize}

\paragraph{Завантаження контейнера PySCF.}
Офіційний образ доступний на GitHub у репозиторії \href{https://github.com/pyscf/pyscf/tree/master/docker}{\texttt{pyscf/docker}}:

\begin{minted}{bash}
# Завантаження останнього образу PySCF
docker pull pyscf/pyscf

# Запуск інтерактивного контейнера
docker run -it pyscf/pyscf /bin/bash
\end{minted}

Після запуску ви опинитесь усередині контейнера, де PySCF уже встановлений і готовий до використання:

\begin{minted}{bash}
python -c "import pyscf; print(pyscf.__version__)"
\end{minted}

\paragraph{Запуск власних скриптів.}
Щоб запустити локальний Python-файл із вашої системи, можна підключити робочий каталог через параметр \texttt{-v}:

\begin{minted}{bash}
docker run -it -v $(pwd):/workspace pyscf/pyscf python /workspace/mycalc.py
\end{minted}

\paragraph{Переваги контейнерного підходу.}
\begin{itemize}
  \item Повна ізоляція середовища --- не впливає на локальні пакети Python.
  \item Ідентична конфігурація на будь-якій системі (Linux, Windows, macOS).
  \item Простота використання на кластерах і у хмарних обчисленнях.
\end{itemize}

\subsection{Розширення та додаткові модулі PySCF}
%% --------------------------------------------------------

Крім основного пакета \texttt{pyscf}, існує низка супутніх бібліотек, що розширюють його можливості.
Деякі з них підтримуються офіційною командою розробників, інші — незалежними групами дослідників,
але сумісні через відкрите API.

\paragraph{Офіційні модулі PySCF (GitHub \href{https://github.com/pyscf}{pyscf/}):}
\begin{itemize}
  \item \href{https://github.com/pyscf/dftd3}{\texttt{pyscf-dftd3}} — емпіричні дисперсійні корекції D3/D4 (Grimme) для \texttt{DFT};
  \item \href{https://github.com/pyscf/geomopt}{\texttt{pyscf-geomopt}} — оптимізація геометрії (на основі \texttt{PyBerny});
  \item \href{https://github.com/pyscf/dmrgscf}{\texttt{pyscf-dmrgscf}} — інтерфейс до \texttt{DMRG} солверів (\texttt{Block2}, \texttt{CheMPS2});
  \item \href{https://github.com/pyscf/nao}{\texttt{pyscf-nao}} — метод природних атомних орбіталей (NAO);
  \item \href{https://github.com/pyscf/qmmm}{\texttt{pyscf-qmmm}} — комбіновані \texttt{QM/MM} розрахунки;
  \item \href{https://github.com/pyscf/cubegen}{\texttt{pyscf-cubegen}} — побудова кубічних сіток густини та орбіталей;
  \item \href{https://github.com/pyscf/properties}{\texttt{pyscf-properties}} — розрахунок молекулярних властивостей (дипольні моменти, поляризовності, ЯМР, спектри);
  \item \href{https://github.com/pyscf/gpu4pyscf}{\texttt{gpu4pyscf}} — прискорення обчислень на GPU.
\end{itemize}


\paragraph{Сторонні розширення, сумісні з PySCF:}
\begin{itemize}
  \item \href{https://github.com/CQCL/pyscf-ac0}{\texttt{pyscf-ac0}} — реалізація методу \texttt{CAS-AC0} (Covalent Approximation);
  \item \href{https://github.com/ZhaoYilin/pyscf-itchem}{\texttt{pyscf-itchem}} — аналіз електронної структури засобами інформаційно-теоретичної хімії;
  \item \href{https://github.com/jparkhill/RealtimePySCF}{\texttt{RealtimePySCF}} — розрахунки в реальному часі (\texttt{TDDFT});
  \item \href{https://github.com/qiskit-community/qiskit-nature-pyscf}{\texttt{qiskit-nature-pyscf}} — інтерфейс між \texttt{PySCF} і квантовими симуляціями у \texttt{Qiskit};
  \item \href{https://github.com/pyscf-ai}{\texttt{pyscf-ai}} — інтеграція з бібліотеками машинного навчання (\texttt{PyTorch}, \texttt{JAX});
  \item \href{https://github.com/pyscf-mpi}{\texttt{pyscf-mpi}} — паралельна реалізація через \texttt{mpi4py}.
\end{itemize}

\paragraph{Встановлення.}
Модулі можна встановити через \texttt{pip}:

\paragraph{Примітки.}
\begin{itemize}

\section{Базова структура програми на PySCF}
%% --------------------------------------------------------

\subsection{Загальна схема розрахунку}

Типовий розрахунок у PySCF складається з трьох основних етапів:

\begin{enumerate}
    \item \textbf{Створення молекулярного об'єкта} --- визначення геометрії системи, базисного набору, заряду та спіну.
    \item \textbf{Вибір та налаштування методу} --- вибір квантово-хімічного методу (HF, DFT, CC тощо).
    \item \textbf{Виконання розрахунку} --- запуск обчислень та отримання результатів.
\end{enumerate}

\paragraph{Примітка.}
Майже всі модулі PySCF дотримуються однакової структури виклику:
\begin{minted}{python}
object = method(mol)
energy = object.kernel()
\end{minted}
Ця уніфікована схема спрощує роботу з різними теоретичними рівнями та дозволяє легко будувати багаторівневі розрахунки.

%% --------------------------------------------------------
\subsection{Мінімальний приклад}
%% --------------------------------------------------------

Розглянемо найпростіший приклад розрахунку атома Гідрогену:

\begin{minted}{python}
from pyscf import gto, scf
# Етап 1: Створення молекулярного об'єкта
mol = gto.M(
atom='H 0 0 0',      # Координати атома
basis='sto-3g',       # Базисний набір
spin=1                # 2S (1 неспарений електрон)
)
# Етап 2: Вибір методу (UHF для відкритої оболонки)
mf = scf.UHF(mol)
# Етап 3: Виконання розрахунку
energy = mf.kernel()
# Виведення результатів
print(f'Енергія атома H: {energy:.8f} Hartree')
print(f'Енергія атома H: {energy * 27.211386:.6f} eV')
\end{minted}

%% --------------------------------------------------------
\subsection{Структура для атома Гелію}
%% --------------------------------------------------------

Для атома з двома електронами у замкненій оболонці:

\begin{minted}{python}
from pyscf import gto, scf
# Атом Гелію
mol = gto.M(
atom='He 0 0 0',
basis='6-31g',
spin=0,               # Всі електрони спарені
charge=0              # Нейтральний атом
)
# RHF для замкненої оболонки
mf = scf.RHF(mol)
energy = mf.kernel()
print(f'Енергія He: {energy:.8f} Ha')
\end{minted}

%% --------------------------------------------------------
\subsection{Розрахунок з аналізом результатів}
%% --------------------------------------------------------

Більш детальний приклад з виведенням додаткової інформації:

\begin{minted}{python}
from pyscf import gto, scf

mol = gto.M(atom='Li 0 0 0', basis='cc-pvdz', spin=1)

mf = scf.UHF(mol)
mf.verbose = 4            # Детальний вивід
energy = mf.kernel()
\end{minted}

%% --------------------------------------------------------
\section{Система одиниць та конвенції}
%% --------------------------------------------------------

%% --------------------------------------------------------
\subsection{Атомні одиниці}
%% --------------------------------------------------------

PySCF використовує атомну систему одиниць (atomic units, a.u.), де:

\begin{align*}
\hbar &= 1  \quad \text{(стала Планка)} \\
m_e &= 1 \quad \text{(маса електрона)} \\
e &= 1 \quad \text{(елементарний заряд)} \\
\end{align*}

У цій системі:
\begin{itemize}
    \item Енергія вимірюється в Hartree (Ha): 1 Ha = 27.211386 eV = 627.509 kcal/mol.
    \item Відстань вимірюється в Bohr ($a_0$): 1 Bohr = 0.529177 \AA.
\end{itemize}

%% --------------------------------------------------------
\subsection{Конвертація одиниць}
%% --------------------------------------------------------

PySCF надає \href{https://github.com/pyscf/pyscf/blob/master/pyscf/data/nist.py}{модуль для конвертації} одиниць вимірювання та фізичних констант:

\begin{minted}{python}

\subsection{Конвенції для атомів}
%% --------------------------------------------------------

\paragraph{Координати.}
Координати задаються у формі рядка або списку. За замовчуванням використовуються ангстреми (Ångström), але можна вказати одиниці:

\begin{minted}{python}
# Координати в Ångströм (за замовчуванням)
mol = gto.M(atom='C 0 0 0')
# Явне вказання одиниць
mol = gto.M(atom='C 0 0 0', unit='Angstrom')
# Координати в Bohr
mol = gto.M(atom='C 0 0 0', unit='Bohr')
\end{minted}

\begin{commentbox}
Параметр \texttt{unit} нечутливий до регістру й приймає декілька синонімів.
За замовчуванням використовується \texttt{'Angstrom'}.
Допустимі значення подані нижче.

\begin{center}
\begin{tblr}{
colspec={ll},
row{1} = {c, font=\bfseries},
hline{1,3} = {-}{0.08em},
}
Фізична одиниця & Допустимі варіанти запису \\
Ангстреми (\si{\angstrom}) & \texttt{'Angstrom'}, \texttt{'angstrom'}, \texttt{'A'}, \texttt{'a'} \\
Бори (атомні одиниці довжини) & \texttt{'Bohr'}, \texttt{'bohr'}, \texttt{'B'}, \texttt{'b'}, \texttt{'AU'}, \texttt{'au'} \\
\end{tblr}
\end{center}
\end{commentbox}

Якщо передано невідоме значення параметра, \texttt{PySCF} генерує помилку типу
\inlinecode{ValueError: Unknown unit <...>}.

\paragraph{Спін.}
Параметр \texttt{spin} визначає $2S = N_\alpha - N_\beta$, де $N_\alpha$ та $N_\beta$ --- кількість альфа та бета електронів:

\begin{minted}{python}
# Атом H (1 неспарений електрон): S=1/2, 2S=1
mol = gto.M(atom='H 0 0 0', spin=1)
# Атом He (всі спарені): S=0, 2S=0
mol = gto.M(atom='He 0 0 0', spin=0)
# Атом O у триплетному стані: S=1, 2S=2
mol = gto.M(atom='O 0 0 0', spin=2)
\end{minted}

\paragraph{Симетрія.}
За замовчуванням PySCF використовує повну точкову симетрію системи:

\begin{minted}{python}
# Автоматичне визначення симетрії
mol = gto.M(atom='Ne 0 0 0', symmetry=True)
print(f'Точкова група: {mol.groupname}')
# Вимкнення симетрії
mol = gto.M(atom='Ne 0 0 0', symmetry=False)
\end{minted}

Окремо варто звернути увагу на велику колекцію \emph{прикладів коду},
згадану в таблиці вище. Вона є одним із найцінніших навчальних ресурсів у екосистемі \texttt{PySCF},
оскільки демонструє практичне застосування майже всіх модулів пакета.

\paragraph{Структура прикладів на GitHub.}
\begin{itemize}
    \item \texttt{scf/} --- базові приклади методів Хартрі---Фока (\texttt{RHF}, \texttt{UHF}, \texttt{ROHF});
    \item \texttt{dft/} --- демонстрації \texttt{DFT} і гібридних функціоналів;
    \item \texttt{mp/}, \texttt{cc/}, \texttt{ci/} --- методи пост-Хартрі-Фока;
    \item \texttt{mcscf/} --- розрахунки з активним простором (\texttt{CASSCF}, \texttt{NEVPT2});
    \item \texttt{pbc/} --- періодичні системи (кристали, твердий стан);
    \item \texttt{prop/} --- розрахунок молекулярних властивостей (дипольні моменти, поляризовності);
    \item \texttt{geomopt/} --- оптимізація геометрії та сканування потенціалів;
    \item \texttt{ao2mo/} --- приклади трансформацій інтегралів та роботи з орбіталями.
\end{itemize}

Кожен приклад є самодостатнім Python-скриптом, який можна без змін запускати після встановлення \texttt{PySCF}.
Це робить репозиторій чудовим навчальним ресурсом як для студентів, так і для викладачів,
а також зручним стартовим майданчиком для розробки власних розрахункових сценаріїв.

\nosection{Резюме}
%% --------------------------------------------------------

У цьому розділі ми познайомились з PySCF --- потужним інструментом для квантово-хімічних розрахунків. Основні моменти:

\begin{itemize}
    \item PySCF є сучасним, відкритим та гнучким програмним пакетом.
    \item Встановлення здійснюється просто через \texttt{pip} або \texttt{conda}.
    \item Базова структура програми включає три етапи: створення системи, вибір методу, виконання розрахунку
    \item PySCF використовує атомну систему одиниць.
    \item Доступна велика кількість документації та навчальних матеріалів.
\end{itemize}

У наступному розділі ми детально розглянемо базові об'єкти PySCF та навчимось налаштовувати параметри розрахунків для атомних систем.
