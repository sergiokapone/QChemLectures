\nosection{Резюме}
%% --------------------------------------------------------

Метод Хартрі--Фока є фундаментальним відправним пунктом \textit{ab initio} квантової хімії.
Він ґрунтується на варіаційному принципі мінімізації енергії системи з використанням детермінанта Слейтера, що гарантує антисиметрію хвильової функції.
Електрони розглядаються як частинки, які рухаються в середньому полі, створеному всіма іншими електронами --- це і є наближення середнього поля.

Основні положення розділу можна підсумувати так:

\begin{itemize}
    \item Рівняння Хартрі--Фока є набором стентних рівнянь для одноелектронних орбіталей, що визначаються оператором Фока.
    \item У базисному представленні метод зводиться до розв’язку матричного рівняння на коефіцієнти розкладу молекулярних орбіталей.
    \item Ітераційна процедура \texttt{SCF} забезпечує збіжність між матрицею густини та оператором Фока до самоузгодженого стану.
    \item Якість результату залежить від вибору базисних функцій --- від мінімальних до розширених (\texttt{STO}, \texttt{GTO}, \texttt{cc-pVXZ} тощо).
    \item Існують різні варіанти методу: \texttt{RHF} (замкнені оболонки), \texttt{UHF} (відкриті оболонки), \texttt{ROHF} (компроміс для відкритих систем), \texttt{GHF} (загальний випадок без розділення спінів).
    \item Метод Хартрі--Фока не враховує миттєву електронну кореляцію, тому його енергія завжди є вищою за точну. Різниця між ними --- це \textit{кореляційна енергія}.
    \item Для відкритооболонкових систем виникає спінове забруднення (\texttt{UHF}), тому контроль значення $\langle S^2 \rangle$ є важливим критерієм достовірності.
    \item На прикладі атомів Гідрогену, Гелію та елементів другого періоду показано здатність методу правильно відтворювати енергетичні рівні, іонізаційні потенціали та електронні густини.
    \item Для складних систем можлива погана збіжність \texttt{SCF}-процедури; подано стратегії її стабілізації --- від добору початкової густини до керування виродженими орбіталями.
\end{itemize}

Метод Хартрі--Фока формує основу для всіх пост-хартрі--фоківських підходів та методів функціоналу густини, тому його розуміння є критично важливим для подальшого вивчення сучасної обчислювальної хімії.

\subsection*{Контрольні запитання}

\begin{enumerate}
    \item Яке основне наближення лежить в основі методу Хартрі-Фока? Поясніть концепцію <<середнього поля>>.
    \item Сформулюйте варіаційний принцип та поясніть, чому енергія HF є верхньою межею до точної енергії.
    \item Що таке детермінант Слейтера? Наведіть його математичний вираз та поясніть роль антисиметрії.
    \item Опишіть структуру рівнянь Хартрі-Фока. Які оператори входять до оператора Фока?
    \item Як виражається енергія системи в наближенні \texttt{HF} через інтеграли? Поясніть роль множника 1/2.
    \item Як представляються спін-орбіталі в базисному наборі? Що таке матриця густини та її роль?
    \item Опишіть \texttt{SCF}-процедуру. Як відбувається ітераційний процес розв'язку рівнянь HF?
    \item Які типи базисних функцій використовуються в HF-обчисленнях? Порівняйте \texttt{STO} та \texttt{GTO}.
    \item Чим відрізняються мінімальні базиси від розширених? Наведіть приклади базисів в PySCF.
    \item Опишіть варіанти методу \texttt{HF}: \texttt{RHF}, \texttt{UHF}, \texttt{ROHF}, \texttt{GHF}. Коли застосовується кожен з них?
    \item Яке явище спінового забруднення в \texttt{UHF}? Як воно впливає на результати?
    \item Як обчислити енергію атомів в \texttt{PySCF}? Наведіть приклад для атома \ce{He}.
\end{enumerate}

    \item Альтернативна форма енергії HF.

    \[
        E_{\text{HF}} = \tfrac{1}{2} \operatorname{Tr}[\mathbf{D} (\mathbf{h} + \mathbf{F})] + E_{\text{nuc}}

    $E_J = \tfrac{1}{2} \Tr(\mathbf{D}\mathbf{J})$, $E_K = -\tfrac{1}{4} \Tr(\mathbf{D}\mathbf{K})$. Перевірте суму.

    Покажіть $\operatorname{Tr}(\mathbf{D} \mathbf{h}) = \sum_i \varepsilon_i - (E_J + E_K)$.

    \item Віріальна теорема.
    Обчисліть $T = \operatorname{Tr}(\mathbf{D} \mathbf{T})$. Перевірте $|V/T + 2| < 10^{-3}$.

    \item Стаціонарність SCF-розв’язку.
